## FAQ

为什么向量化没有加速？

关键问题：
- 向量化版本虽然减少了内存访问次数（从4次变1次），但增加了原子操作次数（从1次变4次）
- 原子操作比内存访问更昂贵，特别是当多个线程竞争同一个内存位置时
