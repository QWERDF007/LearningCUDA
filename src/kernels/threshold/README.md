## FAQ

为什么 float 的向量化没有加速，而 uint8 的有加速？


GPU 内存系统通常以 4 字节、8 字节或更大块为单位进行访问，1 字节访问效率很低

内存带宽利用率差异

uint8_t 情况：
- 单个元素：1 字节
- 向量化后：uchar4 = 4 字节

float 情况：
- 单个元素：4 字节（已经是 GPU 内存系统的基本访问单位）
- 向量化后：float4 = 16 字节

阈值化操作非常简单：只需要一次比较 in[i] > th ? 255 : 0
- 计算开销极小，主要瓶颈是内存访问
- 对于 uint8_t，内存访问是主要瓶颈，向量化能显著改善
- 对于 float，单次 4 字节访问已经比较高效，向量化的收益递减
